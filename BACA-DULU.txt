CARA PASANG (v11: pembagian kamar)
==================================
Folder di zip ini meniru susunan proyekmu (e-voucher). Cukup salin isinya ke folder proyek
dan pilih "Timpa / Replace" untuk file yang sudah ada.

URUTAN
1. Supabase: buka SQL Editor, jalankan  supabase/migration-v11.sql  (sekali saja).
2. Salin semua file di bawah ke proyek (timpa):

   supabase/migration-v11.sql      BARU: tabel kamar dan kolom kamar peserta
   lib/rooms.js                    BARU: status fitur kamar, validasi kamar, data kamar untuk tiket
   app/admin/kamar/page.js         BARU: halaman admin Kamar (daftar kamar, atur penghuni, import/ekspor Excel, tombol aktifkan)
   app/api/admin/route.js          aksi kamar: rooms, setRoomEnabled, addRoom, updateRoom, deleteRoom, roomCandidates, assignRoom, unassignRoom, importRooms (+ catatan History)
   app/api/ticket/route.js         tiket membawa data kamar dan teman sekamar (hanya jika fitur diaktifkan)
   app/page.js                     kartu "Kamar kamu" di tiket peserta + notifikasi saat pembagian kamar masuk
   app/admin/shell.js              menu Kamar di sidebar admin (sebelum Survey)
   app/admin/history/page.js       filter kategori Kamar
   app/theme.css                   gaya kartu kamar, daftar penghuni, label Kamar di History
   lib/excel.js                    template, baca, dan ekspor Excel pembagian kamar
   README.md                       catatan fitur kamar

3. Hentikan "npm run dev", hapus folder .next, lalu jalankan "npm run dev" lagi.
4. Untuk Vercel: commit dan push, lalu tunggu deploy selesai.

CARA PAKAI
- Login sebagai admin, buka menu Kamar.
- Tambah kamar satu per satu (Tambah kamar), atau Import Excel (kolom NIK, Nomor Kamar, Nama Kamar).
- Klik Atur penghuni di tiap kamar untuk memasukkan atau mengeluarkan peserta.
- Kalau acara menginap, klik Aktifkan. Peserta langsung melihat kartu Kamar di tiket (diperbarui otomatis tiap +-25 detik).
- Acara tanpa menginap: biarkan Nonaktif, tiket peserta tidak berubah.
